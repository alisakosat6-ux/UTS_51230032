
## Hosting Gratis

Aplikasi ini dapat di-host gratis di [Streamlit Community Cloud](https://share.streamlit.io/).

1. Unggah `app.py`, `requirements.txt`, dan folder `assets/` ke repository GitHub. Pastikan folder `assets/` menyertakan `logo_unimor.png` dan `foto_profil.jpg`.
2. Masuk ke Streamlit Community Cloud dengan akun GitHub, lalu pilih **Create app**.
3. Pilih repository dan branch yang sudah diunggah, lalu isi **Main file path** dengan `app.py`.
4. Pilih **Deploy**. Setelah proses selesai, Streamlit akan memberikan URL berakhiran `streamlit.app`.

**Catatan keamanan:** login `admin` / `admin123` adalah kredensial demo dan ditampilkan pada halaman login. Siapa pun yang dapat membuka aplikasi bisa melihatnya dan masuk. Jangan gunakan hosting publik ini untuk data transaksi atau informasi pribadi yang sensitif.
